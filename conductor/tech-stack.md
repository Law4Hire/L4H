# Technology Stack

## Backend
- **Language / Framework:** .NET 10 Minimal API (C#)

## Frontend
- **Framework:** React 18 with Vite
- **Styling:** Tailwind CSS

## Database
- **Database Engine:** SQL Server 2022

## Infrastructure & Architecture
- **Architecture:** Monorepo (API + multiple frontends)
- **Containerization:** Docker
- **Orchestration:** Kubernetes (cluster pod storage for each component)
- **Reverse Proxy / Ingress:** Caddy
